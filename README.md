MedSync - Offline First Aid & Editable Prescriptions

Project Description

MedSync is an Android application developed using Android Studio (Java) that enables offline first aid prescriptions and editable prescriptions for users. With Google Firebase integration, it ensures secure data storage and authentication, enhancing accessibility and convenience for patients and healthcare providers.
Features

- Offline First Aid Guidance : Users can access essential first aid prescriptions without internet connectivity.
- Editable Prescriptions : Patients and doctors can modify and save prescriptions securely via Firebase.
- Google Account Login : Authentication via Google Firebase ensures secure user verification before accessing features.
- Personal Information Storage : Allows users to manage and update their health details.

Installation

Clone the repository:
    bash
    git clone https://github.com/yourusername/medsync.git  
    cd medsync 

Install dependencies: Open Android Studio, import the project, and install required dependencies from  build.gradle

Set up Firebase:

- Create a Firebase project in the Firebase Console.
- Enable Google Authentication and Firestore Database for storing prescriptions.
- Download the google-services.json file and add it to your Android project.

Run the application:

- Build and deploy the app using Android Studio.
- Sign in using your Google account to start using MedSync.

Usage

- Access offline first aid guides for emergency situations.
- Modify and save prescriptions with real-time sync via Firebase.
- Securely log in using Google authentication for personalized data access.
